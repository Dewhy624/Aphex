# 🚀 웹사이트 개발 계획서 (Project: APEX Clone)

## 1. 프로젝트 개요
* **목적**: 신뢰감 있는 기업 이미지 전달 및 서비스 소개 (Reference: aphex.co.kr)
* **목표**: 빠른 로딩 속도, 검색 엔진 최적화(SEO), 모바일 최적화(Responsive)
* **핵심 타겟**: 기업 B2B 고객 및 파트너사
* **참조 사이트**: aphex.co.kr
* **개발시 주의사항**: 반드시 한국어로 설명하고 보고할것. 주석도 한국어로 작성할것.
* **변수이름 규칙**: 변수이름은 영어로 작성할것.

---

## 2. 기술 스택 (Tech Stack)
현대적인 웹 표준과 유지보수 효율성을 고려한 조합입니다.

| 구분 | 선택 기술 | 이유 |
| :--- | :--- | :--- |
| **Framework** | **Next.js 15+** | SSR을 통한 SEO 최적화 및 빠른 페이지 전환 |
| **Language** | **TypeScript** | 코드 안정성 확보 및 에러 방지 |
| **Styling** | **Tailwind CSS** | 빠르고 일관된 디자인 시스템 구축 |
| **Animation** | **Framer Motion** | 스크롤 애니메이션 및 부드러운 UI 효과 |
| **Deployment** | **Vercel** | Next.js 최적화 배포 및 자동화(CI/CD) |
| **Icons** | **Lucide React** | 깔끔하고 가벼운 벡터 아이콘 라이브러리 |

---

## 3. 사이트 구조 (Site Map)
참조 사이트의 구성을 바탕으로 한 5개 핵심 섹션입니다.

1.  **Home (Hero)**: 메인 슬로건, 배경 영상/이미지, 스크롤 유도 버튼
2.  **About**: 인사말, 조직도, 기업 가치 소개
3.  **Services**: 서비스 항목 그리드 (카드 형태 UI)
    * *경정청구, IP 전략, 기업 인증 등*
4.  **Portfolio/Partners**: 협력사 로고 슬라이더 및 주요 실적
5.  **Contact**: 문의 정보, 오시는 길(카카오/구글 지도 API), 푸터

---

## 4. 핵심 기능 요구사항
* **반응형 레이아웃**: 데스크탑, 태블릿, 모바일 기기별 최적화 화면 구현
* **스크롤 애니메이션**: 섹션 진입 시 요소들이 위로 올라오며 나타나는 효과
* **Sticky Header**: 스크롤 시 상단 메뉴바 고정 및 배경색 변경
* **SEO 설정**: 각 페이지별 메타 태그(제목, 설명) 및 OpenGraph(공유 시 이미지) 설정

## 5. 개발 일정 (Timeline)

### 1주차: 기획 및 환경 설정
* 요구사항 정의 및 와이어프레임 설계
* Next.js 프로젝트 세팅 및 기본 폰트/컬러 정의 (Tailwind 설정)

* 메인 페이지 섹션별 퍼블리싱 (Framer Motion 적용)

### 3주차: 콘텐츠 최적화 및 테스트
* 실제 텍스트 및 고화질 이미지 삽입
* 크로스 브라우징 테스트 (Chrome, Safari, Mobile)

### 4주차: 배포 및 운영
* Vercel을 통한 도메인 연결 및 최종 배포
* 구글 서치 콘솔 등록 (SEO 등록)
